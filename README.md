# continuity

Menu bar commands to kick Continuity Camera and Mic back to life

Author: Jurre Jan

## Requirements

- Swift 5.9+
- macOS 26.0+

## Getting Started

```bash
swift build
swift run Continuity
```

Or open in Xcode:

```bash
open Package.swift
```

## Common Commands

| Command | Description |
|---------|-------------|
| `swift build` | Build the project |
| `swift run` | Run the app |
| `swift test` | Run tests |

## Project Structure

```
continuity/
  main.swift     # SwiftUI app entry point
Package.swift    # SPM manifest
```
